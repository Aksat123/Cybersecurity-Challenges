# Linux Initial Access Detection

With the rise of **AI**, **cloud computing**, and the **Internet of Things (IoT)**, Linux systems are more popular than ever.  
However, most Linux breaches still begin with **common, well-known Initial Access techniques**.  

This lab will teach you how to **detect and investigate these techniques** using the **log sources** you explored in the *Linux Logging for SOC* room.

---

## 🚀 Learning Objectives
By the end of this room, you will be able to:

- **Understand the role and risk of SSH** in Linux environments  
- Identify how **internet-exposed services** can lead to breaches  
- Perform **process tree analysis** to trace the origin of attacks  
- **Detect Initial Access techniques** through realistic, hands-on labs

---

## 📚 Prerequisites
Before starting, ensure you have the following skills and knowledge:

- Completion of the **Linux Logging for SOC** room  
- Understanding of **MITRE ATT&CK tactics and techniques**  
- Ability to **navigate Linux systems via CLI** (no GUI required)  
- Readiness for a **deep dive into Linux threat detection**
